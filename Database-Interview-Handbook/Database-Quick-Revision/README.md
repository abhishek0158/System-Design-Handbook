# Database Quick-Revision Handbook

A **focused, light** handbook to revise the core database interview topics — fast. Each chapter
gives you the concept **plus the reasoning** (the "why" and the trade-off), so you can explain it
well, not just recite it. Short chapters, simple English, small examples.

This is the quick-read companion to the fuller `Database-Interview-Handbook/` (which has the
deeper versions of these topics if you ever want more).

## How to use it
Read a chapter, then cover the answer and try the **Common Interview Questions** yourself. The
**Quick Recall** at the end of each chapter is for last-minute revision.

Each chapter follows the same shape: **The Idea → Why It Matters (the Reasoning) → Common
Interview Questions → Quick Recall.**
