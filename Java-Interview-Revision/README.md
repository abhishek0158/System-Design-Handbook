# Java Interview Revision Guide — for 3–4 Years Experience

A complete revision guide for **backend Java developers with 3–4 years of experience**
(Spring / Spring Boot). It is made to help you revise fast and cover **all kinds of Java
interview rounds** across companies.

## Who this is for
- You already know Java basics. This guide does **not** teach beginner topics.
- It focuses on the depth interviewers ask at **3–4 years**: how things work inside, trade-offs,
  follow-up questions, and common mistakes.
- The language is kept **simple and easy to read**.

## How to use it
- Each file below is one topic. Read the topic, then test yourself with the questions.
- Every sheet has four parts: **Key Concepts** → **Important Interview Questions (with answers)**
  → **FAQ / Rapid-Fire** → **Common Traps & Gotchas**.
- A single combined file, `Java-Interview-Revision-Guide.md`, joins all topics into one page
  for easy scrolling and search.

## A quick note on interview rounds
Most companies run 2–4 Java-focused rounds. They usually mix these buckets:
1. **Core Java + OOP** (sheets 1–3)
2. **Concurrency + JVM** (sheets 4–5)
3. **Java 8 / Modern Java** (sheets 6–7)
4. **Frameworks: Spring + Hibernate** (sheets 9–10)
5. **Design + REST/microservices + SQL** (sheets 8, 11)
6. **Coding round** (sheet 13)

Revise in that order for the best coverage.
